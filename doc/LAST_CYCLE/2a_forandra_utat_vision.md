# Steg 2a: Förändra utåt (Vision & Gränssnitt)

## 1. Yttre gränssnittsförändring
- **Total avsaknad av text**: Skärmen rensas från alla rubriker, menyer, titlar och etiketter. All kommunikation sker via harmoniska bildbrickor.
- **Dynamisk partitionering**: Skärmen delas upp adaptivt mellan 1–3 externa talare plus afasideltagarens dedikerade kontrollzon.
- **Tomt utgångsläge**: Zoner startar tomma och rena.
- **Frågetecken-överlägg (`?`)**: Vid medelhög osäkerhet (0.50–0.80) markeras ikonen med ett transparent frågetecken.
- **Scen-brickor**: 4 stora scenikoner i användarens zon för att starta låtsassamtal:
  - Kaffekopp (Fikasamtal med vän)
  - Kundvagn (Butik / Handla)
  - Stetoskop/Hjärta (Läkarbesök / Vård)
  - Hem/Tallrik (Familjemiddag)
- **Feedbackreglage**: Stor grön bock (bekräfta/korrekt) och rött kryss (avfärda tolkning).

## 2. Visuell och ergonomisk design
- Palett: Skiffergrå (`stone-900`), dämpad salvia (`emerald-800`), varm sand (`amber-700`) och terrakotta.
- Touch-mål: Minst 64px per bildbricka, tydliga hover/aktiva states för pekskärm.
- Tillgänglighet: WCAG AAA kontrast på ikoner mot bakgrund.
